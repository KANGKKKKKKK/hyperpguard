感谢您使用 HyperPGuard。

本次更新加了自定义规则，并给未拦截的域名标注用途。

## 新增

- 「自定义规则」：填域名（拦该域及其子域）或 域名/路径（只拦该前缀），对所有作用域应用生效
- 「未拦截」行按内置表标注用途，例如统计埋点、广告位、病毒引擎日志、网络助手、游戏加速
- 安全中心新增「广告位与推送下发」：广告位配置、网络助手推送、满意度问卷
- 系统安全组件新增「引擎日志上传」：`logupdate.avlyun.sec.miui.com`，不影响本地查毒

## 说明

- 规则与开关存在同一份配置里，本地被清理时会回落到 Settings 读取
- 添加或删除规则后需要重启对应应用，规则在注入时装配
