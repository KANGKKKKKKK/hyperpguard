感谢您使用 HyperPGuard。

这一版加了首次启动的条款确认，并去掉一处多余的按压反馈。

## 新增

- 首次启动（或免责声明版本变化后）弹出摘要并要求确认，文案取 `DISCLAIMER.txt` 正文，按钮「我已阅读」写入版本号后不再弹出
- 英文界面下展示文件末尾的 English Summary 摘要；摘要前注明「与中文正文冲突时以中文为准」

## 调整

- 「关于」区域的 GitHub 仓库 / LSPosed 模块页 / 问题反馈 / 检查更新去掉按压变色，恢复普通行样式；其它位置的按压反馈不变

## 说明

- 弹窗跟随深浅色，切换主题时就地换色
- 拦截逻辑与默认值未改动
